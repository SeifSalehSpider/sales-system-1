# sales-system-1

نظام إدارة مبيعات "الفارس لمستلزمات السباحة و احذية الاطفال" — نسخة سطح المكتب (Electron) ونسخة ويب تعمل من المتصفح.

## الرابط (نسخة الويب)

https://seifsalehspider.github.io/sales-system-1/

## التشغيل

### نسخة سطح المكتب
```bash
npm install
npm start
```

بناء ملف التثبيت:
```bash
npm run release:win
```

### نسخة الويب (GitHub Pages)
```bash
npm run build:web
```
الأمر بينسخ التطبيق إلى مجلد `docs/` (الصفحة الرئيسية `docs/index.html` والتطبيق في `docs/app/`).
GitHub Actions بيرفع المجلد ده تلقائياً على Pages مع كل push على فرع `main`.

لازم تفعّل Pages مرة واحدة من: **Settings → Pages → Source: GitHub Actions**.

## حفظ البيانات في نسخة الويب
- البيانات بتتحفظ تلقائياً داخل المتصفح (localStorage) بعد كل تعديل.
- من بطاقة **💾 حفظ بيانات نسخة الويب** تقدر تربط ملف `data.json` على جهازك فيتحفظ فيه تلقائياً.
- زر **💾 نسخة احتياطية** بيحفظ نسخة كاملة من البيانات.

## ملاحظات أمان
- `license-private.pem` (مفتاح إصدار الأكواد) **مش مرفوع** على GitHub — متجاهل بالكامل في `.gitignore`.
- نسخة الويب بدون بوابة ترخيص/تجربة، بوابة التفعيل شغالة في نسخة سطح المكتب فقط.
